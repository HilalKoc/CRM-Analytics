# CRM Analytics

A collection of customer relationship management (CRM) analytics case studies, focused on turning raw customer transaction data into actionable business decisions.

Each case study lives in its own folder with its own dataset description, methodology, and results.

## Case Studies

| Case Study | Description | Status |
|---|---|---|
| [RFM Customer Segmentation](./rfm) | Segments customers by Recency, Frequency, and Monetary value; used to drive two real targeted marketing campaigns | ✅ Complete |
| [CLTV Prediction](./cltv_prediction) | Predicts future customer lifetime value using probabilistic models (BG/NBD & Gamma-Gamma) | ✅ Complete |

## Tools & Libraries

- Python 3.x
- pandas
- lifetimes (for CLTV prediction)
